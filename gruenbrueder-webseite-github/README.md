# Grünbrüder – Webseite

Eine moderne, responsive One-Page-Webseite für das Grünbrüder Gartenunternehmen.

## Dateien

- `index.html` – Seiteninhalt
- `style.css` – Design und responsive Layout
- `script.js` – Navigation und Termin-Anfrage
- `images/` – hier eure eigenen Bilder ablegen

## Vor dem Veröffentlichen

In `index.html` bitte ersetzen:

- `+49 123 4567890` → echte Telefonnummer
- `info@gruenbrueder.de` → echte E-Mail
- WhatsApp-Link `https://wa.me/491234567890` → echte WhatsApp-Nummer
- Beispielbewertungen → echte Kundenbewertungen
- Beispielbilder → echte Vorher-/Nachher-Fotos

## GitHub Pages

1. Neues GitHub Repository erstellen, z. B. `gruenbrueder-webseite`.
2. Alle Dateien aus diesem Ordner hochladen.
3. GitHub: **Settings → Pages**
4. Bei Source **Deploy from a branch** auswählen.
5. Branch `main` und Ordner `/ (root)` wählen.
6. Speichern.

Danach stellt GitHub Pages die Webseite unter der GitHub-Pages-Adresse bereit.

## Terminbuchung

Die erste Version ist bewusst ohne Server aufgebaut. Das Formular erstellt beim Absenden eine vorbereitete E-Mail.

Für echte Online-Termine kann später ein Buchungssystem eingebaut werden, ohne das komplette Design neu zu machen.
